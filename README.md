# MarkEconly Website

Clean, modern, bilingual (English + Chinese) website focused on marketing and economics insights + free business tools.

## Files
- `index.html` — Main page
- `styles.css` — Styles
- `script.js` — Language switch + calculators

## How to Deploy (Recommended: Vercel)

1. Create a free account at [vercel.com](https://vercel.com)
2. Install Vercel CLI (optional) or just use the website
3. Push this folder to a GitHub repository
4. In Vercel dashboard → New Project → Import the GitHub repo
5. Deploy (it will automatically detect static site)
6. Connect your domain `markeconly.com` in Vercel → Settings → Domains

### Alternative: Netlify or Cloudflare Pages
Same process — drag & drop the folder or connect GitHub.

## Local Preview
Just open `index.html` in your browser, or run a local server:

```bash
npx serve .
```
