MarkEconly Research Check 独立试验版

1. 双击 research-check.html 即可在浏览器中打开（如果浏览器限制本地脚本，请用本地静态服务器）。
2. 上传随包的 MarkEconly_synthetic_survey_test.csv。
3. ID 列选择 respondent_id；1to5 三列默认启用 1–5 范围检查。
4. 手动给 age 勾选范围检查，最小 18，最大 100。
5. 点击 Run data checks。预期：100 行、6 列、缺失单元格 2、量表越界 2、年龄无效 1、完全重复 1、重复 ID 1。
6. 下载 JSON 和异常行 CSV，核对结果。

注意：此试验版不改变已有 MarkEconly 网站。不要把整个 ZIP 上传到现有网站根目录覆盖文件。
若要公开测试，建议单独使用一个新仓库/测试站，确保所选托管方案允许你的实际用途。
浏览器本地处理不代表设备绝对安全；请先使用合成数据。不要上传个人敏感数据。
不自动删除记录，不提供统计显著性、量表效度、抽样代表性判断。
