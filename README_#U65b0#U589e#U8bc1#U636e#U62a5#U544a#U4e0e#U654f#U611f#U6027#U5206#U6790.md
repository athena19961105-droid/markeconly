# MarkEconly 新功能：问卷声明证据报告与排除敏感性分析

## 安装
本压缩包基于上一版 MarkEconly_Tools_Entry_Fix.zip。将 `markeconly-main` 目录内部文件上传到 GitHub 对应位置，不要嵌套额外目录。推荐先在测试分支部署。

## 使用
1. 打开 `research-check.html`，上传不含个人敏感信息的 CSV（限 2 MB）。
2. 在第 4 部分选择题目、回答选项，输入可选的目标百分比，点击核对。
3. 在第 5 部分勾选想要比较的排除规则，点击 Compare scenarios。
4. 查看原始/模拟结果、有效分母和差异；下载 JSON 或打印保存 PDF。

## 重要限制
- 这是敏感性分析，不是推荐删除数据；原始 CSV 不会被改动。
- 范围检查采用当前在第 2 部分启用的规则。若勾选“排除无效范围”，范围检查中的空白也会被排除。
- 完全重复和重复 ID 规则采用按原始顺序保留首条记录的方法；并不证明被标记的记录无效。
- 证据报告仅核对精确选项计数；不能确认样本代表性、题目效度、因果结论或广告法律合规性。
- 第 5 部分新功能提供英文、简体中文、繁体中文界面；其他语言暂时回退英文，避免误称已经完整翻译。
- 仅对代码语法与 Node 测试完成检查，尚未在实际 Vercel 部署和浏览器中全面验收。

## 测试
在项目根目录执行 `node test.js` 与 `node test-claim-enhancements.js`。
