# MarkEconly 全站简体中文更新（第一种语言）

## 本次范围
- 全部 10 个 HTML 页面；包括 3 篇文章的现有完整中文正文。
- 首页原有的 9 语言选项保留；本次只完善简体中文（zh-CN），**其他语言的完整正文尚未制作**。
- 跨页面语言偏好使用 `markeconly-language`。原始英文仍然可切回。
- Research Check 静态界面、常见运行提示、数据检查结果和数字声明摘要可显示简体中文；数据列名、用户回答、CSV/JSON 导出中的技术字段保持原样，防止改变数据含义。

## 关键修改
- 新增 `i18n-zh.js`：简体中文词条。
- 新增 `i18n-zh-runtime.js`：跨页面语言切换与动态文字更新。
- 修改 10 个 HTML 文件的脚本引用。
- 文章页面不再加载仅供首页计算器使用的 `script.js`，避免找不到计算器元素而抛错。
- 保留原有 `checker.js` 和业务逻辑。

## GitHub 上传
1. 先备份原仓库，推荐建立测试分支。
2. 解压 ZIP，将 `markeconly-main` 文件夹**里面**的文件及 `articles/` 子目录上传到 GitHub 仓库对应位置，不要再嵌套一层文件夹。
3. 确认 `i18n-zh.js` 和 `i18n-zh-runtime.js` 位于网站根目录。
4. 预览部署后测试：在首页选择简体中文 → 点击 Services / Portfolio / Sample Report / Insights / 三篇文章 / Research Check / Contact → 返回首页，确认语言保留。
5. Research Check 请使用合成 CSV，不要上传真实个人敏感数据。

## 验证与限制
- 10 个 HTML 页面的可见静态英语内容进行了词条覆盖审计；代码语法检查已执行。
- 当前环境的浏览器自动化被管理员阻止，**没有完成真实浏览器端的端到端验收**。请先部署到测试分支/预览环境，避免直接覆盖正式站。
- 这不是其他 7 种非中文语言的全文翻译包。其他语言仍按原有基础版本处理。
- 动态生成的任意第三方数据、原始 CSV 值、部分低频异常提示可能仍保留英文；上线前需进一步验收。
