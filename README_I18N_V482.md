# MarkEconly v4.8.2 — 中文界面补译与语言源修正（测试版）

基于 Survey Claim Checker Bilingual Pilot 完整网站包。

- 修正首页 script.js 的 zh-CN 翻译值：此前许多 zh-CN 条目实际上仍是英文。
- 增补全站字典中截图指出的英文提示、导航与报告状态。
- 让运行时翻译不再跳过首页带 data-i18n 的文本节点。
- 为主要翻译脚本增加版本参数，减少浏览器继续读取旧缓存的可能。
- 不修改 CSV 统计、分子分母、审计与导出算法。

## 验证建议

1. 部署到同一个 Vercel 项目，不要同时比较不同项目域名。
2. 首页切换简体中文，核对服务卡片、三步流程、关于我们、页脚。
3. Research Check 检查情景比较按钮、排除条件、报告按钮及动态输出。
4. 切换 English，确认英文能够恢复；刷新页面确认语言保存。

**限制：** 本次是已知漏译与语言机制修复，不代表对所有页面、所有动态结果完成浏览器端到端验收；原始 CSV 列名、英文问卷值、代码字段不会翻译。
