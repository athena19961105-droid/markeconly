# MarkEconly v4.9 — 第二阶段：主页词典实质修复

此包在 v4.9 审计基线上修改了 `script.js` 中的主页多语言词典。原先繁体中文、法语、德语、西班牙语、葡萄牙语、日语、韩语各有 23 个与英文原文完全相同的长文本；本次补齐了这些内容，另外补译了少量同类字段。英文、简体中文内容保持原样。

## 本次已验证
- 主页词典：英文基准的 48 个键在其他 8 种语言中均存在；长度超过 14 字符且完全照搬英文的值为 0。
- `script.js` JavaScript 语法检查通过。
- 这不是九语言全站完成版。其它 HTML 页面的硬编码英文、Research Check 的动态计算提示、PDF/JSON 报告、文章正文尚未完整本地化。英文词语在少量技术名称中仍可能合理存在。

## 使用
将 `markeconly-main` 内的文件上传至现有 GitHub 仓库根目录覆盖，等待部署。建议先在预览部署测试九种语言的首页，再合并正式站点。不要将此包宣传为“全站翻译已完成”。
