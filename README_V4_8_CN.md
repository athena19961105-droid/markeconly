# MarkEconly v4.8 中文界面修复测试版

本版基于 v4.7，仅增强 Research Check 的简体中文界面与动态结果翻译，不改动审计算法。

## 安装
将 markeconly-main 内部文件覆盖 GitHub 仓库根目录。部署后在 Research Check 顶部选择「简体中文」，按 Cmd+Shift+R 强制刷新。

## 验证
1. 检查第 1–11 节标题、按钮、表单提示是否显示中文。
2. 上传 v44_multiple_response_test.csv，运行第 9 节，并在第 11 节生成报告，检查结果中文。
3. 切换 English，再切回简体中文，确认计算结果不变。
4. CSV 列名、文件名、JSON 机器字段保留原文是刻意设计，不是漏译。

## 限制
一些长篇动态警告和旧模块产生的非固定英文语句仍可能需要补充翻译；请截图反馈。报告 JSON 继续使用稳定英文键。
