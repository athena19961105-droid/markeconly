# MarkEconly 繁體中文（zh-TW）增量更新

此版本以已驗證的簡體中文全站版本為基礎，加入繁體中文。

## 上傳
將本 ZIP 中 `markeconly-main/` **內的文件**上傳至 GitHub 專案對應位置，不要額外嵌套資料夾。先在測試分支／Vercel Preview 驗證，再合併主分支。

## 更新文件
- `i18n-zh-tw.js`：繁體中文詞典（由簡體中文詞典轉換，做了部分臺灣常用詞調整）
- `i18n-article-tw.js`：三篇文章既有簡體中文全文的繁體中文對應文字
- `i18n-zh-runtime.js`：擴展為支援 zh-CN 與 zh-TW
- 10 個 HTML 頁面：載入上述新詞典

## 已知限制
- 本版繁體中文內容以簡體中文翻譯為基礎轉換，尚未經專業母語審校。
- Research Check 中上傳的 CSV 欄位名稱、回答選項、匯出 JSON 的機器可讀鍵名保持原樣。
- 尚未在實際 Vercel 網站進行瀏覽器端完整驗收。
